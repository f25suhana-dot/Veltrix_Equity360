# EQUITY360 — Veltrix HR case competition prototype

Run locally:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Four modules: Executive Overview, Pay Equity Diagnostics, Budget Optimizer, Retention & Trust.

**Important:** Employee-level data are synthetic. Case-wide metrics come from the Veltrix case brief. Category allocations, optimizer weights, and forecast targets are assumptions, not factual results. The ₹48 crore total is treated as an annualised correction requirement solely for scenario modelling. The optimization reserves legally required corrections first and allocates the remainder among illustrative discretionary categories.
